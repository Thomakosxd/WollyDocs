# 📃 Channels & Roles

Customize where Wolly posts bump reminders, who gets pinged when the cooldown expires, and how the reminder embed looks to fit your server's style\[cite: 2\].

---

## 1. Setting up a Bump Channel

You can choose exactly where Wolly posts the reminder embed when a bump becomes available\[cite: 2\].

<Tabs>
  <Tab icon="rocket" label="⚡ Automatic Setup">
    Run `/bumpping createchannel`\[cite: 2\]. Wolly will automatically create a dedicated `#bump-here` text channel and set it as your reminder destination\[cite: 2\].
  </Tab>
  <Tab icon="setting" label="🛠️ Manual Setup">
    If you already have an existing channel (e.g., `#bot-commands`), run `/bumpping setchannel #channel` to link it\[cite: 2\].
  </Tab>
</Tabs>

---

## 2. Setting up a Ping Role

Notify a specific group of members whenever it is time to bump again\[cite: 2\].

<Tabs>
  <Tab icon="rocket" label="⚡ Automatic Setup">
    Run `/bumpping createrole`\[cite: 2\]. Wolly will create a mentionable `👊Bump ME` role with a cyan color and assign it to the system\[cite: 2\].
  </Tab>
  <Tab icon="setting" label="🛠️ Manual Setup">
    If you already have a role for bumpers, run `/bumpping setpingrole @role` to set it\[cite: 2\].
  </Tab>
</Tabs>

<Note>
  If no role is configured, Wolly will mention the user who performed the last bump instead\[cite: 2\].
</Note>

---

## 3. Customizing Embed Messages <Badge text="💎 Premium" variant="caution" />

Make the reminder alerts match your server's vibe by customizing the embed text and timestamps\[cite: 2\].

<CardGroup cols={2}>
  <Card title="Change Title" icon="pencil">
    Run `/bumpping setembedtitle title:<your_title>` to set a custom header\[cite: 2\].
  </Card>

  <Card title="Change Description" icon="document">
    Run `/bumpping setembeddesc description:<your_text>`\[cite: 2\].
  </Card>

  <Card title="Toggle Timestamps" icon="clock">
    Run `/bumpping timestamps status:<ON/OFF>` to display or hide exact time details inside embeds\[cite: 2\].
  </Card>
</CardGroup>

<Tip>
  Use the `{time}` variable inside your description text, and Wolly will automatically swap it with the actual cooldown duration\[cite: 2\].
</Tip>
