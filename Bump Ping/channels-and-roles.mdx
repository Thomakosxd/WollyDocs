# 1. Setting up a Bump Channel

You can choose exactly where Wolly posts the reminder embed when a bump becomes available.

<Tabs>
  <Tab title="⚡ Automatic Setup" icon="bolt" iconType="regular">
    Run `/bumpping createchannel`. Wolly will automatically create a dedicated `#bump-here` text channel and set it as your reminder destination.
  </Tab>
  <Tab title="🛠️ Manual Setup" icon="wrench" iconType="regular">
    If you already have an existing channel (e.g., `#bot-commands`), run `/bumpping setchannel #channel` to link it.
  </Tab>
</Tabs>

<Note>
  If no channel is configured, Wolly will send the message to the channel that had the last bump.
</Note>

## 2. Setting up a Ping Role

Notify a specific group of members whenever it is time to bump again.

<Tabs>
  <Tab title="⚡Automatic Setup" icon="bolt" iconType="regular">
    Run `/bumpping createrole`. Wolly will create a mentionable `👊Bump ME` role with a cyan color and assign it to the system.
  </Tab>
  <Tab title="🛠️ Manual Setup" icon="wrench" iconType="regular">
    If you already have a role for bumpers, run `/bumpping setpingrole @role` to set it.
  </Tab>
</Tabs>

<Note>
  If no role is configured, Wolly will mention the user who performed the last bump instead.
</Note>

## 3. Customizing Embed Messages 💎 Premium

<Warning>
  As of now, there is NO way to get Premium. This is just a BETA for now. You’ll be notified in the support server when there’s a way to get premium!
</Warning>

Make the reminder alerts match your server's vibe by customizing the embed text and timestamps.

<Info>
  Timestampts is auto ON when you have premium. You can turn it off though.
</Info>

<CardGroup cols={2}>
  <Card title="Change Title" icon="pencil">
    Run `/bumpping setembedtitle title:<your_title>` to set a custom header.
  </Card>

  <Card title="Change Description" icon="pencil">
    Run `/bumpping setembeddesc description:<your_text>`.
  </Card>

  <Card title="Toggle Timestamps" icon="clock">
    Run `/bumpping timestamps status:<ON/OFF>` to display or hide exact time details inside embeds.
  </Card>
</CardGroup>

<Tip>
  Use the `{time}` variable inside your description text, and Wolly will automatically swap it with the actual cooldown duration.
</Tip>
