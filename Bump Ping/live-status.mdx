# ⏱️ Live Countdown Channel

Want your members to see when the next bump is ready at a glance? Wolly can create a locked voice channel that displays the remaining cooldown timer directly in your channel list.

---

## How to Enable It

Simply run the command:

```text
/bumpping statuschannel
```

Wolly will automatically create a locked voice channel configured with your current status prefix.

- **During Cooldown:** The channel name displays the remaining time (e.g., `👊 Bump: In 1h 30m`).
- **When Ready:** The channel updates to `👊 Bump: Ready!`.

_(Note: To respect Discord rate limits, status channel names update every 10 minutes)._

---

## Customizing the Prefix

You can easily change the prefix or emojis displayed before the status text.

Run the command:

```text
/bumpping setstatusname name:<prefix>
```

**Example:**

If you type `/bumpping setstatusname name:🚀 Disboard`, your channel name will display as:

- `🚀 Disboard: In 1h 30m`
- `🚀 Disboard: Ready!`
