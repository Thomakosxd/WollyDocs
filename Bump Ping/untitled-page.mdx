## 1. How it Works

<Steps>
  <Step title="Automatic Tracking">
    Every time a user successfully uses the `/bump` command and the Disboard bot replies with a success message, the system automatically adds \+1 to their bump count.
  </Step>
  <Step title="No Setup Required">
    The counting system works out of the box as long as the bot is in your server and can read the Disboard messages.
  </Step>
</Steps>

## 2. Available Commands

<Warning>
  As of now, there is NO way to get Premium. This is just a BETA for now. You’ll be notified in the support server when there’s a way to get premium!
</Warning>

Here are the commands you can use to check bump statistics.

<AccordionGroup>
  <Accordion title="Bump Count">
    `/bumpping count [user]` Check how many times a specific user (or yourself) has successfully bumped the server.

    <Tip>
      Leave the `[user]` option blank to instantly see your own bump count.
    </Tip>
  </Accordion>

  <Accordion title="💎 Bump Leaderboard (Premium)">
    `/bumpping bumpleaderboard` 💎 Displays the top 20 users who have bumped the server the most.

    <Warning>
      This command is exclusive to servers with an active Premium subscription. It's a great way to host weekly or monthly bump competitions for your members!
    </Warning>
  </Accordion>
</AccordionGroup>
