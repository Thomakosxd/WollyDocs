# 🤗 /fun hug

Send a heartwarming hug accompanied by a live anime cuddling GIF.

---

## Usage

```text
/fun hug user:@member
```

## Behaviors

- **Self-Hugging:** If you hug yourself, Wolly displays a humorous self-isolation message.
- **Interactive Gifs:** Automatically embeds custom anime hug GIFs from the `Nekos.best API`.
