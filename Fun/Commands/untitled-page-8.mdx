# 🎲 /fun dice

Roll dice matching standard tabletop formatting criteria (NdM format).

---

## Usage

```text
/fun dice roll:2d6
```

## Parameters

- `roll` _(optional, default: `1d6`)_: String expression representing quantity and sides (e.g., `1d20`, `3d8`).
- **Constraints:** Maximum 100 dice allowed per roll (`n <= 100`), minimum 2 sides (`m >= 2`).
