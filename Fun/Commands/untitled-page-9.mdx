# 💖 /fun love

Run an algorithmic compatibility check between two members complete with a custom progress block bar.

---

## Usage

```text
/fun love user1:@member1 user2:@member2
```

## Score Tiers

- **\> 80%:** A perfect match! ❤️
- **\> 50%:** Looking pretty good together! ✨
- **\> 20%:** Needs a bit more effort. 💬
- **\< and = 20%:** Maybe just stay friends... 😅
