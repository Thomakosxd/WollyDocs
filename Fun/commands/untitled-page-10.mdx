# 🔮 /fun whoismostlikely

Ask the Wolly Oracle to choose which of the nominated server members fits a custom scenario best.

---

## Usage

```text
/fun whoismostlikely prompt:sleep through an earthquake user1:@member1 user2:@member2 user3:@member3
```

## Parameters

- `prompt` _(Required)_: The behavior or scenario description ("Who is most likely to...").
- `user1` & `user2` _(Required)_: Primary candidate users to choose from.
- `user3`, `user4`, `user5` _(Optional)_: Extra candidates to expand the pool.
