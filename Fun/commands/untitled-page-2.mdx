# 💡 /fun advice

Fetch a random, thoughtful piece of advice to share with the channel.

---

## Usage

```text
/fun advice
```

## How It Works

1. Wolly requests a random quote slip from the external `Advice Slip API`.
2. If the API is offline or fails, Wolly automatically falls back to a curated local list of safety advice.
