# 💥 /fun slap

Playfully slap, smack, or bonk a target member with a dynamic action verb and GIF.

---

## Usage

```text
/fun slap user:@member
```

## Behaviors

- Randomly selects an action string (`slaps`, `smacks`, or `bonks`).
- Self-targeting prompts a witty error message (`...bonked themselves... Why?`).
- Pulls dynamic slap reaction GIFs from the `Nekos.best API`.
