# ✨ /fun joke

Read a funny setup and click the spoiler tag to reveal the punchline.

---

## Usage

```text
/fun joke
```

## Features

- Supports multi-part setup/delivery jokes safely using `JokeAPI`'s safe mode.
- Hides the punchline inside Discord spoiler tags (`||text||`) so users can guess before reading.
