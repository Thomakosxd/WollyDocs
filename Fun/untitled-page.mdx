# 🎉 Fun Module Overview

The **Fun** module brings entertainment, interaction, and humor to your Discord server through a wide selection of `/fun` subcommands. Powered by external APIs and built-in fallbacks, it ensures endless engagement for your community.

---

## Available Subcommands

- **[Advice](./advice.mdx):** Receive random pieces of life advice.
- **[Dadjoke](./dadjoke.mdx):** Get classic, humorous dad jokes.
- **[Fact](./fact.mdx):** Learn random, interesting trivia facts.
- **[Joke](./joke.mdx):** Read multi-part jokes with hidden spoiler punchlines.
- **[Quote](./quote.mdx):** Be inspired by randomized quotes from notable figures.
- **[Hug](./hug.mdx):** Send warm virtual hugs complete with anime GIFs.
- **[Slap](./slap.mdx):** Playfully slap, bonk, or smack server members.
- **[Dice](./dice.mdx):** Roll customizable tabletop dice (e.g., `2d6`, `1d20`).
- **[Love](./love.mdx):** Test relationship compatibility with a live progress bar meter.
- **[WhoIsMostLikely](./who.mdx):** Let the oracle pick which tagged user is most likely to do something.
