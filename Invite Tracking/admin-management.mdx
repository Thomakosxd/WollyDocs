# ⚙️ Admin Management

Administrators can manually adjust bonus invites for users, useful for rewarding event winners, compensating for lost data, or correcting counts.

> 🔒 **Permission Required:** Administrators

---

## 1. Add Bonus Invites

Adds a specific number of bonus invites to a user's existing total.

```text
/invitetracking add user:@member amount:5
```

---

## 2. Remove Bonus Invites

Deducts bonus invites from a user's total.

```text
/invitetracking remove user:@member amount:3
```

---

## 3. Set Exact Bonus Invites

Overrides a user's current bonus invite count and sets it to an exact value.

```text
/invitetracking set user:@member amount:10
```
