All invite tracking functionality is grouped under the `/invitetracking` slash command\[cite: 2\].

## Member Commands

<AccordionGroup>
  <Accordion title="/invitetracking user [user]" icon="user">
    Displays detailed invite statistics for yourself or the specified user\[cite: 2\].

    **Parameters:**

    - `user` _(Optional)_: The member whose stats you want to view\[cite: 2\].

    **Output includes:**

    - **Total Invites:** All-time joins plus bonus invites\[cite: 2\].
    - **Still in Server:** Net invites currently present\[cite: 2\].
    - **Left:** How many invited users have left\[cite: 2\].
    - **Joins & Bonus:** Individual breakdown\[cite: 2\].
  </Accordion>

  <Accordion title="/invitetracking leaderboard" icon="trophy">
    Displays the Top 10 inviters in the server\[cite: 2\]. Includes an interactive **🔄 Refresh** button to update rankings live\[cite: 2\].
  </Accordion>

  <Accordion title="/invitetracking help" icon="circle-question">
    Displays a list of all available commands directly in Discord\[cite: 2\].
  </Accordion>
</AccordionGroup>

## Administrator Commands

<Warning>
  These commands require **Administrator** permissions on the server.
</Warning>

<AccordionGroup>
  <Accordion title="/invitetracking add <user> <amount>" icon="plus">
    Adds a specified number of bonus invites to a member\[cite: 2\].
  </Accordion>

  <Accordion title="/invitetracking remove <user> <amount>" icon="minus">
    Subtracts bonus invites from a member\[cite: 2\].
  </Accordion>

  <Accordion title="/invitetracking set <user> <amount>" icon="sliders">
    Sets a member's bonus invites to an exact number\[cite: 2\].
  </Accordion>
</AccordionGroup>
