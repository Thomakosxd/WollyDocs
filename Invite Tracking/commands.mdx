All invite tracking functionality is grouped under the `/invitetracking` slash command.

## Member Commands

<AccordionGroup>
  <Accordion title="/invitetracking user [user]" icon="user">
    Displays detailed invite statistics for yourself or the specified user.

    **Parameters:**

    - `user` _(Optional)_: The member whose stats you want to view.

    **Output includes:**

    - **Total Invites:** All-time joins plus bonus invites.
    - **Still in Server:** Net invites currently present.
    - **Left:** How many invited users have left.
    - **Joins & Bonus:** Individual breakdown.
  </Accordion>

  <Accordion title="/invitetracking leaderboard" icon="trophy">
    Displays the Top 10 inviters in the server. Includes an interactive **🔄 Refresh** button to update rankings live.
  </Accordion>

  <Accordion title="/invitetracking help" icon="circle-question">
    Displays a list of all available commands directly in Discord.
  </Accordion>
</AccordionGroup>

## Administrator Commands

<Warning>
  These commands require **Administrator** permissions on the server.
</Warning>

<AccordionGroup>
  <Accordion title="/invitetracking add <user> <amount>" icon="plus">
    Adds a specified number of bonus invites to a member.
  </Accordion>

  <Accordion title="/invitetracking remove <user> <amount>" icon="minus">
    Subtracts bonus invites from a member.
  </Accordion>

  <Accordion title="/invitetracking set <user> <amount>" icon="sliders">
    Sets a member's bonus invites to an exact number.
  </Accordion>
</AccordionGroup>
