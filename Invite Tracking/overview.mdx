# 📥 Invite Tracking Overview

Wolly features a built-in, real-time Invite Tracker that monitors server growth, calculates active invites, and maintains accurate leaderboards without requiring complex setup.

---

## How It Works

1. **Automatic Caching:** Wolly automatically caches all server invite links upon joining or restarting.
2. **Join Detection:** When a new member joins, Wolly compares invite link usage to credit the correct inviter.
3. **Leave Tracking:** If a member leaves, Wolly deducts 1 point from the inviter's total count.
4. **Formula:**
   $$\text{Current Invites} = (\text{Joins} + \text{Bonus}) - \text{Leaves}$$

---

## Required Permissions

To ensure the Invite Tracking module functions correctly, Wolly needs the following permissions:

* **Manage Server** (or **Manage Webhooks / Invites**) — Needed to read invite codes and usages.
* **Embed Links** & **Use External Emojis** — Needed to render the stats and leaderboard embeds properly.
