## Overview

**Invite Logs** is a Premium feature that posts an automatic notification in a designated text channel whenever a new member joins using a tracked invite link.

## Configuration Commands

<Note>
  These commands require **Administrator** permissions and an **Active Premium Subscription** for the guild.
</Note>

### Set Log Channel

To enable invite logging, select the text channel where notifications should be sent:

```bash
/invitetracking setchannel <channel-name>
```

### Remove Log Channel

To disable automatic invite logging:

```bash
/invitetracking removechannel
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Premium Required Error">
    If you receive a `🔒 Premium Required` error, make sure your server's premium subscription is active. Contact support if you believe this is an error.
  </Accordion>

  <Accordion title="Logs are not sending">
    Ensure that the bot has the **View Channel** and **Send Messages** permissions in the channel selected with `/invitetracking setchannel`.
  </Accordion>
</AccordionGroup>
