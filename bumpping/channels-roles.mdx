# 📢 Channels & Roles

If you want Wolly to remind the whole server instead of just DMing the user, you can easily set up a dedicated bump channel and a ping role.

## 1. Setting up a Bump Channel

You can tell Wolly to send the reminder in a specific channel. 

* **The easy way:** Run `/bumpping createchannel`. Wolly will automatically create a brand new channel called `#bump-here` and set it as the reminder channel.
* **The custom way:** If you already have a channel (e.g., `#bot-commands`), use `/bumpping setchannel <channel>` to select it.

## 2. Setting up a Ping Role

Want to notify a specific group of people when it's time to bump?

* **The easy way:** Run `/bumpping createrole`. Wolly will instantly create a role named `@👊Bump ME` and link it. Members can grab this role to get pinged.
* **The custom way:** If you already have a "Bumper" role, simply use `/bumpping setpingrole <role>` to assign it.

## 3. Customizing the Message (Optional)

You can make the reminder message fit your server's theme!
* **`/bumpping setembedtitle <title>`**: Changes the title of the reminder embed.
* **`/bumpping setembeddesc <description>`**: Changes the text. Use the keyword `{time}` in your text, and Wolly will automatically replace it with a Discord timestamp!
