# 🛠️ Managing Your Setup

Once you have set up your channels, roles, and status, you might want to double-check everything or make changes down the road.

## Check Your Settings

Not sure what channel is set for reminders? Just run:
**`/bumpping info`**

This command will display a clean, organized panel showing:
* The current Bump Channel
* The Ping Role
* The Status Channel
* Whether the 2nd Reminder (30-minute warning) is ON or OFF.

## Starting Fresh

If you ever want to completely reset the Bumper module for your server, the Server Owner can run:
**`/bumpping deletealldata`**

> **Warning:** This will wipe all saved bump settings (channels, roles, custom embeds) for your server. Wolly will revert to the default "Plug & Play" behavior (DMing the user).
