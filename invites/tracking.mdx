# 🔗 Invite Tracker

Wolly's Invite Tracker helps you see exactly how your server is growing. It tracks which invite links are being used, who created them, and how many people each member has successfully invited.

## How it works

The moment you invite Wolly to your server, it starts tracking invites automatically in the background. It monitors when members join, which invite code they used, and calculates the inviter's total count.

## User Commands

Members can easily check their own invite stats or see who is leading the server.

| Command | Description |
| :--- | :--- |
| `/invites [user]` | Check how many people you (or another member) have invited to the server. Displays total joins, leaves, and real invites. |
| `/leaderboard invites` | Displays the top inviters in your server. Great for hosting invite rewards or events! |

## Setup Join/Leave Logs (Admins)

Want to see exactly who joins and who invited them in real-time? You can set up an invite log channel!

**Command:** `/setinvitelog <channel>`
* **Permission Required:** `Administrator`
* **What it does:** Every time a user joins, Wolly will send a message in this channel saying: *“Welcome **@User**! Invited by **@Inviter** (They now have 5 invites).”*

If you ever want to turn this off, just use `/disableinvitelog` or delete the channel.
