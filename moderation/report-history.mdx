# 📋 Reports & History

Wolly doesn't just punish rule-breakers; it helps you keep track of everything that happens in your server.

## 👤 User Reports

If a member sees someone breaking the rules, they can use Wolly to alert the staff privately.

**Command:** `/report <member> <reason>`
* **Who can use it:** Everyone!
* **How it works:** The user selects the member and types a reason. Wolly sends an alert embed directly to the designated staff channel (configured via `/setreportchannel`). 
* *Note: Users cannot report themselves!*

## 🔍 Checking Case History

Staff members can pull up the moderation history of any user or check a specific case using its ID.

### View a Specific Case
**Command:** `/case <case_id>`
Did you see Wolly log "Case #15"? Type `/case 15` to see exactly who was punished, which staff member took action, the reason, and the exact timestamp.

### View a User's Full History
**Command:** `/modhistory <member>`
If you want to know if a user has been a repeat offender, use this command. Wolly will display the last 10 moderation actions taken against that specific member.
