# ⚙️ Moderation Setup

Wolly's moderation system is designed to protect your server effortlessly. 

## Toggle Moderation (Owner Only)

By default, the moderation module is enabled. If you ever want to completely turn off Wolly's moderation commands for your server, the Server Owner can toggle it.

**Command:** `/modtoggle <True/False>`
* Set to `False` to disable all mod commands.
* Set to `True` to turn them back on.

## Set up the Report Channel

Wolly allows regular members to report rule-breakers directly to the staff. To make this work, you need to tell Wolly where to send these reports.

**Command:** `/setreportchannel <channel>`
* Example: `/setreportchannel #staff-logs`

Once set, any reports submitted by members will automatically appear in this channel in a clean, easy-to-read embed.
