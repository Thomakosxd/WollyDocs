# Privacy Policy

By inviting or using Wolly, you agree to how we handle data as described below.

## 1. What Data We Collect

To function properly, Wolly collects and stores minimal necessary data:

- **Server & Channel IDs:** To save configuration settings (e.g., bump channels, report channels, ticket channels) and know where to send reminders or logs.
- **Role IDs:** To know which roles to ping or assign (e.g., bump roles, staff roles).
- **User IDs & System Records:** We store User IDs connected to moderation actions (warnings, mutes, kicks, bans) to maintain case history, as well as for ticket logging and invite tracking.
- **Command Usage:** We may temporarily log command errors to diagnose and fix bugs.

## 2. What We Don't Collect

- We do not log, read, or store the content of regular chat messages (unless required for temporary processing, like `/purge`, after which the data is immediately discarded).
- We do not sell, share, or distribute any of your server's data to third parties.

## 3. Data Storage & Security

- All configuration data, moderation cases, and ticket logs are stored securely in our database.
- If you want to remove your server's bumper data completely, you can run the `/bumpping deletealldata` command (Server Owner only), or kick the bot to halt all active features.

## 4. Third-Party Services

- The bot is hosted on **Bot-Hosting**, which provides the hosting infrastructure. We ensure that our database is kept private and secure at all times.
